# Guía de Pruebas: Suite de Cliente Tramposo

### Resumen Rápido de Uso

```bash
# Menú interactivo (Recomendado para la defensa):
python pruebas/tramposo.py

# Ejecutar todos los 20 casos:
python pruebas/tramposo.py --todos

# Ejecutar por categoría (1 a 4):
python pruebas/tramposo.py --categoria 1
python pruebas/tramposo.py --categoria 2
python pruebas/tramposo.py --categoria 3
python pruebas/tramposo.py --categoria 4

# Ejecutar casos específicos:
python pruebas/tramposo.py --robar-servicio
python pruebas/tramposo.py --espiar-flota
python pruebas/tramposo.py --publicar-otra-fuerza
python pruebas/tramposo.py --posicion-mar

# Ver todos los casos disponibles:
python pruebas/tramposo.py --listar
```
